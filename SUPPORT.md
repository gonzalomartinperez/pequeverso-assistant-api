# Support

- **Questions and usage help:** open a GitHub issue with the **Feature request** form and describe what you are trying to do.
- **Bugs:** open an issue with the **Bug report** form; include the version or commit and the steps to reproduce.
- **Security issues:** never in public issues; follow [SECURITY.md](SECURITY.md).

This is a single-maintainer project. Issues are triaged weekly; there is no guaranteed response time and no paid support.
